# M6 后续扩展：FAT32 终端卷支持

**日期：2026-10-02**

在完成 M6 核心回归后，终端的内存字节数组文件卷已经扩展为可以挂载和操作
FAT12、FAT16 以及 FAT32 superfloppy 卷。该支持服务于 DOS 会话的文件句柄、
FCB 和查找接口；它不是宿主文件系统直通，也不会让普通 ISO 自动变成 FAT32。

## 已实现

- 读取 FAT32 BPB：32 位总扇区数、FAT 大小、根目录起始簇和数据区边界；
- 32 位簇号和 28 位 FAT 项，保留 FAT32 项的高四位；
- 根目录作为普通簇链处理，而不是 FAT12/FAT16 的固定根目录区；
- 跨簇读写、创建、截断、删除、查找和碎片化簇链；
- FAT32 目录项的高/低簇号合并；
- `FindFirst/FindNext` 的内部 DTA continuation 状态改为保存完整 32 位目录簇号；
- 双 FAT 副本同步，以及损坏链、环、越界簇和超长文件的拒绝。

## 验收

`dos/tests/test_fat.c` 新增 70,000 簇的合成 FAT32 卷，覆盖：

- FAT32 挂载和根目录识别；
- 预置文件读取；
- 根目录新文件创建、写入、回读；
- 32 位簇号路径不会被旧的 16 位字段截断。

当前回归结果：

```text

```

## 边界

- 仍然使用内存中的 byte-array backend，重启后不持久化；
- 当前 DOS 磁盘映像生成流程仍默认使用 FAT12，FAT32 需要显式提供/挂载 FAT32
  映像；
- 长文件名、VFAT 短名别名、exFAT、分区表和宿主块设备 I/O 不在本次范围内；
- 文件大小和内存映像仍受 FunnyOS 32 位偏移及可用 guest 内存限制。
